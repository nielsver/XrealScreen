Privacy policy

Short version: the XrealScreen app collects no personal data and sends nothing anywhere. This website has no cookies, no analytics and no trackers.

Last updated: 25 October 2026

The XrealScreen app

  • No data collection. The app has no telemetry, no analytics, no crash reporting to a server, no ads and no account.
  • No internet connection. The app doesn't contact any server. The only web link in it is a button that opens the driver download page on GitHub in your browser, and only when you select it.
  • Glasses data stays local. Head-tracking data from the glasses arrives over the glasses' own USB link (the address 169.254.2.1, which exists only between your PC and the glasses). It is used live and isn't recorded.
  • Screen capture stays local. To show the virtual monitors in the glasses, the app captures them with Windows screen capture. The images go straight to the graphics card and are never saved or sent. Windows shows that capture is active.
  • Local API. The optional developer API is a named pipe that only your own Windows user can open. It isn't reachable from the network or from web pages. You can switch it off under Settings → Developers.

What the app stores on your PC

Only settings that make the app work. Nothing leaves your PC, and uninstalling or deleting the folders removes it all.

WhereWhat
%LOCALAPPDATA%\XrealScreen\settings.json, app.jsonYour workspace and app settings
%LOCALAPPDATA%\XrealScreen\workspaces\Workspaces you saved
%LOCALAPPDATA%\XrealScreen\topology-snapshot.jsonYour monitor layout while a workspace runs, so it can be restored after a crash
%LOCALAPPDATA%\XrealScreen\crash.logTechnical error details, only if the app crashes. It stays on your PC unless you choose to send it to us.
Pictures\XrealScreen\Glasses screenshots, only when you take one

If you turn on Start with Windows, Windows stores that choice: in the Startup apps list for the Store version, or in your user's Run registry key for the MSI version.

This website

  • No cookies, analytics or trackers. The site loads no third-party scripts, fonts or embeds. Everything comes from this server.
  • Theme choice. If you select light or dark theme, your browser saves that choice locally (localStorage). It is never sent to us.
  • Server logs. Like every web server, our web host records technical request data: IP address, date and time, the page requested, browser type and referring page. It is used only to run and protect the site (security, error analysis), it isn't combined with other data, and it is deleted according to the host's retention policy. The legal basis is our legitimate interest in running a secure website (GDPR article 6(1)(f)).
  • Email. If you email us, we use your address and message only to answer you, and delete them when they are no longer needed.

Third parties

  • GitHub hosts the source code and the downloads. When you open GitHub or download a release, GitHub's privacy statement applies.
  • Microsoft Store. If you install XrealScreen from the Store, Microsoft's privacy statement covers the Store itself. We receive only the anonymous aggregate statistics that Partner Center gives every publisher.

Your rights

Under the GDPR you have the right to access, correct or delete personal data about you, to object to processing, and to complain to a supervisory authority (in Sweden, IMY). Since the app collects nothing, the only data we could have about you is in server logs or emails. Contact us and we'll help.

Contact

Questions about privacy: xrealscreen@timeonline.se.
