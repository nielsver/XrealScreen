Build on XrealScreen

Read head tracking from the glasses in your own .NET program, or control the running app from any language. Everything is open source under the MIT license.

Read the developer docs Browse the samples

Two ways to build

.NET SDK

Read the glasses yourself, in your own process. No XrealScreen app needed.

  • Head pose at about 1000 Hz, with recenter
  • Reconnects by itself when the glasses are unplugged
  • Head-to-mouse engine for games
  • Helpers for the glasses monitor (find it, make it primary)

Use it for a game mod, a visualizer, a research tool or your own head tracking.

Local API

Control the running app from any language: JSON-RPC 2.0 over the named pipe \\.\pipe\XrealScreen.Api.

  • Start and stop saved workspaces, recenter
  • Head look on or off, and its settings
  • Glasses screenshots, status events
  • Head poses at up to 250 Hz while the app tracks

Use it for scripts, hotkeys, stream decks and automation.

.NET SDK: head pose in a few lines

Package XrealScreen.Sdk, for net10.0-windows10.0.26100.0.

using XrealScreen.Sdk;

var glasses = new XrealGlasses();                          // default address 169.254.2.1
glasses.ConnectionChanged += (_, e) =>
    Console.WriteLine(e.IsConnected ? "connected" : $"waiting: {e.Error}");

await foreach (var pose in glasses.ReadPosesAsync(cancellationToken))
{
    // ~1000 poses per second
    Console.WriteLine($"yaw {pose.Yaw:F1}  pitch {pose.Pitch:F1}  roll {pose.Roll:F1}");
}

No glasses at hand? The samples run against a built-in simulator:

dotnet run --project samples/HeadPose.Console -- --simulate

Local API: control the app from Python

Turn on Settings → Developers in the app (it's on by default). The sample client uses only the Python standard library:

from xrealscreen_api import XrealScreenApi

with XrealScreenApi("my script") as api:
    print(api.call("status.get")["workspace"]["state"])
    api.call("headLook.start")
    api.call("pose.subscribe", {"rateHz": 10})
    for _ in range(50):
        message = api.next_notification()
        if message["method"] == "pose":
            print(message["params"]["yaw"])

PowerShell works too:

.\samples\powershell\XrealScreenApi.ps1 -Method workspace.start -Params @{ name = 'Desk' }

For .NET there is a typed client, XrealScreen.Sdk.Client. Full protocol reference →

Security

  • The pipe accepts only the Windows user who runs XrealScreen.
  • Web pages can't open named pipes. That's why the API isn't a localhost web server, which any web page could reach.
  • The API can switch the primary monitor and move the mouse (head look). It can't run programs or read files. Turn it off under Settings → Developers.
