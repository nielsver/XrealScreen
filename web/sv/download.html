Skaffa XrealScreen

Gratis och öppen källkod, för Windows 11. Installera, ställ in glasögonens meny för den arbetsyta du vill ha, och starta.

Förhandsversion. XrealScreen fungerar hela vägen med XREAL 1S, och installationsprogrammet testas fortfarande. Förhandsversionerna är inte kodsignerade än, så Windows SmartScreen kan varna: välj Mer information → Kör ändå. Om en nedladdningslänk inte har någon fil än, använd Bygg från källkod.

Installera

  1. Ladda ner XrealScreen-<version>-x64.msi från den senaste versionen på GitHub.
  2. Dubbelklicka på filen: Welcome → License → Install folder → Virtual display driver (låt rutan vara markerad om du inte redan har en) → Install. Windows ber om administratörsrättigheter.
  3. Starta XrealScreen från Start-menyn. Appen finns också i meddelandefältet.

Drivrutinen i förhandsversionen är signerad med ett testcertifikat. Installationsprogrammet frågar innan certifikatet läggs till i Windows, eftersom Windows bara installerar drivrutiner som datorn litar på. Avinstallation tar bort drivrutinen och certifikatet igen, om XrealScreen installerade dem.

Tyst installation för IT 
msiexec /i XrealScreen-0.1.0-x64.msi /qn /l*v install.log     # app + drivrutin
msiexec /i XrealScreen-0.1.0-x64.msi /qn INSTALLDRIVER=0       # bara appen
msiexec /x XrealScreen-0.1.0-x64.msi /qn                       # avinstallera
Kom igång

Ställ in glasögonen

Vilken inställning glasögonen behöver beror på typen av arbetsyta. Välj typ på appens sida Screens och ställ sedan in glasögonens meny (knappen på glasögonen):

ArbetsytaGlasögonens menyPassar för
Glasses anchorLäget Anchor + UltraWide 32:9, 21:9 eller 16:18Stabilast bild, långa arbetspass, 1–3 skärmar
App head trackingLäget Follow, UltraWide av, Stabilizer avUpp till 6 skärmar runt dig i en båge eller ett rutnät

Din första arbetsyta

  1. Koppla glasögonen till datorn. Windows visar dem som en skärm.
  2. Öppna XrealScreen. Välj Check connection på sidan Device.
  3. Välj typ av arbetsyta och antal skärmar på sidan Screens, och ställ in glasögonens meny enligt tabellen ovan.
  4. Välj Start workspace på startsidan, eller tryck Ctrl+Alt+W. De nya skärmarna dyker upp i Windows. Dra fönster till dem.
  5. Stoppa med samma knapp eller kortkommando. Din vanliga skärmlayout kommer tillbaka.

Med Glasses anchor och UltraWide avstängt väntar XrealScreen och startar av sig själv när du slår på UltraWide.

Kortkommandon

TangenterFunktion
Ctrl+Alt+WStarta eller stoppa arbetsytan
Ctrl+Alt+PSpara en skärmbild av det glasögonen visar (Bilder\XrealScreen)

Ctrl+Alt+GFlytta det aktiva spelfönstret till glasögonen

Huvudstyrning i spel

För spel använder du sidan Games i stället för en arbetsyta. Ställ glasögonen på Follow med UltraWide av. Medan huvudstyrningen körs blir glasögonen huvudskärm, så spel öppnas där. Välj Look (kameran följer huvudet 1:1) eller Joystick (vrid huvudet för att fortsätta svänga).
