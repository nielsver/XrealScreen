Integritetspolicy

I korthet: XrealScreen-appen samlar inte in några personuppgifter och skickar ingenting någonstans. Den här webbplatsen har inga kakor, ingen statistik och inga spårare.

XrealScreen-appen

  • Ingen datainsamling. Appen har ingen telemetri, ingen statistik, ingen kraschrapportering till någon server, ingen reklam och inget konto.
  • Ingen internetanslutning. Appen kontaktar ingen server. Den enda webblänken i appen är en knapp som öppnar drivrutinens nedladdningssida på GitHub i din webbläsare, och bara när du väljer den.
  • Glasögonens data stannar lokalt. Huvudrörelserna från glasögonen kommer via glasögonens egen USB-länk (adressen 169.254.2.1, som bara finns mellan datorn och glasögonen). De används direkt och spelas inte in.
  • Skärminspelningen stannar lokalt. För att visa de virtuella skärmarna i glasögonen spelar appen in dem med Windows skärminspelning. Bilderna går direkt till grafikkortet och sparas eller skickas aldrig. Windows visar när inspelning pågår.
  • Lokalt API. Det valfria utvecklar-API:et är en named pipe som bara din egen Windows-användare kan öppna. Det går inte att nå från nätverket eller från webbsidor. Du kan stänga av det under Settings → Developers.

Det här sparar appen på din dator

Bara inställningar som behövs för att appen ska fungera. Ingenting lämnar datorn, och allt försvinner om du avinstallerar eller tar bort mapparna.

VarVad
%LOCALAPPDATA%\XrealScreen\settings.json, app.jsonDina inställningar för arbetsytan och appen
%LOCALAPPDATA%\XrealScreen\workspaces\Arbetsytor du har sparat
%LOCALAPPDATA%\XrealScreen\topology-snapshot.jsonDin skärmlayout medan en arbetsyta körs, så att den kan återställas efter en krasch
%LOCALAPPDATA%\XrealScreen\crash.logTekniska feldetaljer, bara om appen kraschar. Filen stannar på din dator om du inte själv väljer att skicka den till oss.
Bilder\XrealScreen\Skärmbilder av glasögonen, bara när du tar en

Om du slår på Start with Windows sparar Windows det valet: i listan över autostartappar för Store-versionen, eller i din användares Run-nyckel i registret för MSI-versionen.

Den här webbplatsen

  • Inga kakor, ingen statistik och inga spårare. Webbplatsen laddar inga skript, typsnitt eller inbäddningar från tredje part. Allt kommer från den här servern.
  • Val av tema. Om du väljer ljust eller mörkt tema sparar webbläsaren valet lokalt (localStorage). Det skickas aldrig till oss.
  • Serverloggar. Som alla webbservrar loggar vårt webbhotell teknisk information om anrop: IP-adress, datum och tid, vilken sida som hämtades, webbläsartyp och hänvisande sida. Uppgifterna används bara för att driva och skydda webbplatsen (säkerhet, felsökning), kombineras inte med andra uppgifter och raderas enligt webbhotellets lagringstid. Den rättsliga grunden är vårt berättigade intresse av att driva en säker webbplats (artikel 6.1 f i GDPR).
  • E-post. Om du mejlar oss använder vi din adress och ditt meddelande bara för att svara dig, och raderar dem när de inte längre behövs.

Tredje parter

  • GitHub lagrar källkoden och nedladdningarna. När du besöker GitHub eller laddar ner en version gäller GitHubs integritetspolicy.
  • Microsoft Store. Om du installerar XrealScreen från Store gäller Microsofts sekretesspolicy för själva Store. Vi får bara den anonyma, sammanställda statistik som Partner Center ger alla utgivare.

Dina rättigheter

Enligt GDPR har du rätt att få tillgång till, rätta eller radera personuppgifter om dig, att invända mot behandling och att klaga hos en tillsynsmyndighet (i Sverige IMY). Eftersom appen inte samlar in något kan vi bara ha uppgifter om dig i serverloggar eller e-post. Kontakta oss så hjälper vi dig.
