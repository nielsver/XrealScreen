Bygg vidare på XrealScreen

Läs glasögonens huvudrörelser i ditt eget .NET-program, eller styr appen från valfritt språk. Allt är öppen källkod under MIT-licensen.

Läs utvecklardokumentationen Se exemplen

Dokumentationen och exemplen är på engelska.

Två sätt att bygga

.NET-SDK

Läs glasögonen själv, i din egen process. XrealScreen-appen behövs inte.

  • Huvudets riktning i cirka 1000 Hz, med centrering
  • Ansluter igen av sig själv när glasögonen kopplas ur
  • Motor som gör huvudrörelser till musrörelser i spel
  • Hjälpfunktioner för glasögonskärmen (hitta den, gör den till huvudskärm)

Använd den till en spelmod, en visualisering, ett forskningsverktyg eller din egen huvudföljning.

Lokalt API

Styr appen från valfritt språk: JSON-RPC 2.0 över named pipe \\.\pipe\XrealScreen.Api.

  • Starta och stoppa sparade arbetsytor, centrera
  • Huvudstyrning på eller av, och dess inställningar
  • Skärmbilder av glasögonen, statushändelser
  • Huvudets riktning i upp till 250 Hz medan appen följer huvudet

Använd det till skript, kortkommandon, Stream Deck och automatisering.

.NET-SDK: huvudets riktning på några rader

Paketet XrealScreen.Sdk, för net10.0-windows10.0.26100.0.

using XrealScreen.Sdk;

var glasses = new XrealGlasses();                          // default address 169.254.2.1
glasses.ConnectionChanged += (_, e) =>
    Console.WriteLine(e.IsConnected ? "connected" : $"waiting: {e.Error}");

await foreach (var pose in glasses.ReadPosesAsync(cancellationToken))
{
    // ~1000 poses per second
    Console.WriteLine($"yaw {pose.Yaw:F1}  pitch {pose.Pitch:F1}  roll {pose.Roll:F1}");
}

Inga glasögon till hands? Exemplen kan köras mot en inbyggd simulator:

dotnet run --project samples/HeadPose.Console -- --simulate

Lokalt API: styr appen från Python

Slå på Settings → Developers i appen (det är på från början). Exempelklienten använder bara Pythons standardbibliotek:

from xrealscreen_api import XrealScreenApi

with XrealScreenApi("my script") as api:
    print(api.call("status.get")["workspace"]["state"])
    api.call("headLook.start")
    api.call("pose.subscribe", {"rateHz": 10})
    for _ in range(50):
        message = api.next_notification()
        if message["method"] == "pose":
            print(message["params"]["yaw"])

PowerShell fungerar också:

.\samples\powershell\XrealScreenApi.ps1 -Method workspace.start -Params @{ name = 'Desk' }

För .NET finns en typad klient, XrealScreen.Sdk.Client. Fullständig protokollreferens →

Säkerhet

  • Bara den Windows-användare som kör XrealScreen kan öppna API:ets pipe.
  • Webbsidor kan inte öppna named pipes. Därför är API:et ingen webbserver på localhost, som vilken webbsida som helst skulle kunna nå.
  • API:et kan byta huvudskärm och flytta musen (huvudstyrning). Det kan inte köra program eller läsa filer. Stäng av det under Settings → Developers.
