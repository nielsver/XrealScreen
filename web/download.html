Get XrealScreen

Free and open source, for Windows 11. Install it, set the glasses menu for the workspace type you want, and start.

Preview. XrealScreen works end to end on the XREAL 1S, and the installer is still being tested. The preview builds are not code-signed yet, so Windows SmartScreen may warn you: select More info → Run anyway. If a download link shows no file yet, use Build from source.

Requirements

WindowsWindows 11, x64
GlassesXREAL 1S, the only model tested so far
ConnectionA USB-C port with DisplayPort video (DP Alt Mode) that the glasses plug straight into
DriverA virtual display driver (virtual-display-rs, MIT). The MSI can install it. An existing copy is kept.

Install

  1. Download XrealScreen-<version>-x64.msi from the latest GitHub release.
  2. Double-click it: Welcome → License → Install folder → Virtual display driver (leave it checked unless you already have one) → Install. Windows asks for administrator rights.
  3. Start XrealScreen from the Start menu. It also runs in the tray.

The preview driver is signed with a test certificate. The installer asks before it adds that certificate to Windows, because Windows installs only drivers it trusts. Uninstalling removes the driver and the certificate again, if XrealScreen installed them.

Silent install for IT 
msiexec /i XrealScreen-0.1.0-x64.msi /qn /l*v install.log     # app + driver
msiexec /i XrealScreen-0.1.0-x64.msi /qn INSTALLDRIVER=0       # app only
msiexec /x XrealScreen-0.1.0-x64.msi /qn                       # uninstall
Setup guide

Set up the glasses

Which glasses setting you need depends on the workspace type. Choose the workspace type on the app's Screens page, then set the glasses menu (the button on the glasses):

Workspace typeGlasses menuGood for
Glasses anchorAnchor mode + UltraWide 32:9, 21:9 or 16:18Steadiest picture, long work sessions, 1–3 screens
App head trackingFollow mode, UltraWide Off, Stabilizer offUp to 6 screens around you in an arc or grid

Your first workspace

  1. Plug the glasses into the PC. Windows shows them as a monitor.
  2. Open XrealScreen. On the Device page, select Check connection.
  3. On the Screens page, pick the workspace type and the number of screens, then set the glasses menu as in the table above.
  4. Select Start workspace on the Home page, or press Ctrl+Alt+W. The new monitors appear in Windows. Drag windows onto them.
  5. Stop again with the same button or hotkey. Your normal monitor layout comes back.

In Glasses anchor with UltraWide off, XrealScreen waits and starts by itself once you switch UltraWide on.

Hotkeys

KeysAction
Ctrl+Alt+WStart or stop the workspace
Ctrl+Alt+PSave a screenshot of what the glasses show (Pictures\XrealScreen)
Ctrl+Alt++ / −Move the screens closer or further away (App head tracking)
Ctrl+Alt+HHead look for games on or off
Ctrl+Alt+CRecenter head look
Ctrl+Alt+GMove the active windowed game to the glasses

Head look for games

For games, use the Games page instead of a workspace. Set the glasses to Follow with UltraWide Off. While head look runs, the glasses become the primary monitor, so games open there. Choose Look (the camera follows your head 1:1) or Joystick (turn your head to keep turning).
