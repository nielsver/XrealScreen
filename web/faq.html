FAQ

Frequently asked questions

Didn't find your answer? Open an issue on GitHub or email xrealscreen@timeonline.se.

General

Is XrealScreen an official XREAL app?

No. XrealScreen is an independent open-source project. It is not affiliated with or endorsed by XREAL. It doesn't use the XREAL SDK, which is for Unity and Android only.

Which glasses does it support?

The XREAL 1S. It is the only model tested so far, so it is the only one supported for now.

What does it cost?

Nothing. XrealScreen is free and open source under the MIT license. There are no ads and no account.

Does it work on Windows 10, macOS or Linux?

No, only Windows 11. It relies on Windows 11 display and screen-capture features.

Using it

Which workspace type should I choose?

Glasses anchor is the most stable: the glasses keep their own UltraWide picture still, and XrealScreen splits it into 1–3 screens. Most people start here.

App head tracking gives you up to six screens around you, tracked by the app. Use it when you want more screens than fit in the UltraWide picture.

Glasses anchor doesn't start. Home says it is waiting for UltraWide.

Set the glasses menu to Anchor and UltraWide 32:9, 21:9 or 16:18. XrealScreen starts the workspace by itself a few seconds after the glasses switch.

In App head tracking, the screens drift or wobble.

Check the glasses menu: Follow mode, UltraWide Off and Stabilizer off. The glasses' own stabilizer fights the app's tracking. On the Tracking page, try the Strong stabilizer preset and the Full tracking axes, and recenter.

Why does it need a virtual display driver?

To give Windows real extra monitors, so every app can use them. XrealScreen uses the open-source virtual-display-rs driver (MIT). The MSI installer can install it, and it keeps a copy that is already installed (for example from another XREAL tool).

My monitor layout is wrong after a crash.

XrealScreen restores your layout and refresh rates the next time it starts. You can also run xrs recover from the install folder. It removes leftover virtual monitors and restores the layout.

Windows warns me when I run the installer.

The preview builds are not code-signed yet, so SmartScreen shows a warning. Select More info → Run anyway. Signed builds are planned for the first public release.

Can I play games with head tracking?

Yes. The Games page turns head movement into mouse movement, with no driver, so the camera follows your head. It has been tested in Skyrim. Use Follow mode with UltraWide Off, and don't run a workspace at the same time. Games that run as administrator ignore the mouse moves unless XrealScreen also runs as administrator.

Privacy and security

Does XrealScreen collect data or need internet?

No. The app has no telemetry, no account and no online features, and it works offline. See the privacy policy.

The app captures my screens. Where do the images go?

Nowhere. The capture of the virtual monitors goes straight to the GPU and onto the glasses, and it is never saved or sent. Only a screenshot you take yourself (Ctrl+Alt+P) is saved, to your Pictures\XrealScreen folder.
