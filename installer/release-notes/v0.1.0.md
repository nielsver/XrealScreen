# XrealScreen 0.1.0 — preview (test build)

XrealScreen turns **XREAL 1S / One / One Pro** glasses into a virtual multi-monitor workspace on Windows 11: real virtual monitors you can drag windows onto, shown in the glasses either anchored by the glasses (Glasses anchor, UltraWide) or head-tracked by the app. It also has **head look for games** and a developer SDK + local API.

> ⚠️ **Preview / test build.** This is the first MSI release. It has been tested on the developer's PC only. The installer and the virtual display driver are signed with **test certificates**, not with a trusted code-signing certificate. Read *Security* below before you install.

## Download
| File | What |
|---|---|
| **`XrealScreen-0.1.0-x64.msi`** | **The installer — this is all you need.** App, `xrs` tool and virtual display driver in one file. |
| `XrealScreen-Driver.zip` | Only the virtual display driver with a PowerShell installer — for the Microsoft Store version of XrealScreen. MSI users do not need it. |

## Requirements
- **Windows 11, 64-bit (x64).** ARM64 PCs and Windows 10 are not supported by this MSI.
- Administrator rights to install.
- XREAL 1S, One or One Pro connected by USB-C (video + data). Tested with the **XREAL 1S**, firmware 15.01.03.522.
- Nothing else: .NET and the Windows App SDK are included.

## Install
1. Download `XrealScreen-0.1.0-x64.msi` and double-click it.
2. **SmartScreen** may show *"Windows protected your PC"* → **More info** → **Run anyway** (the MSI is not signed yet).
3. The wizard: **Welcome → License (MIT) → Install folder → Virtual display driver → Install**. Windows asks for administrator rights; the prompt shows **Unknown publisher**.
4. Start **XrealScreen** from the Start menu.

Silent install (admin PowerShell):
```powershell
msiexec /i XrealScreen-0.1.0-x64.msi /qn /l*v install.log                 # app + driver
msiexec /i XrealScreen-0.1.0-x64.msi /qn INSTALLDRIVER=0                  # app only
msiexec /i XrealScreen-0.1.0-x64.msi /qn INSTALLDIR="D:\Apps\XrealScreen\"
```

## Security — please read
- **The MSI and the app are unsigned.** Windows shows *Unknown publisher*. Only install it if you trust this repository.
- **The virtual display driver** ([virtual-display-rs](https://github.com/MolotovCherry/virtual-display-rs) 0.4, MIT, built unmodified from source) is signed with a **self-signed test certificate**, *XrealScreen Driver (test)*. Windows only installs such a driver when that certificate is trusted, so — if you leave **Install the virtual display driver** checked — Setup adds it to this PC's **Trusted Root** and **Trusted Publishers** certificate stores. While it is there, Windows trusts anything signed with that certificate. Uninstalling XrealScreen removes the certificate again.
- If a virtual-display-rs driver is **already installed** (for example by VertoXR), Setup keeps it and does **not** add the certificate.
- Without the driver, XrealScreen cannot create virtual screens (the Home page says so); head look for games still works.
- A future release will use a trusted code-signing certificate and a Microsoft-signed driver.

## Set up the glasses
| Workspace type | Glasses menu (OSD) |
|---|---|
| **Glasses anchor** (most stable) | **Anchor** + **UltraWide 32:9, 21:9 or 16:18** |
| **App head tracking** | **Follow**, UltraWide **Off**, Stabilizer **off** |

## Uninstall
Settings → Apps → Installed apps → **XrealScreen** → Uninstall (or `msiexec /x XrealScreen-0.1.0-x64.msi`).
This removes the app, the Start menu entry, *Start with Windows*, and the driver + test certificate **if this installer added them**. Your settings stay in `%LOCALAPPDATA%\XrealScreen` (delete the folder for a clean slate).

Quit XrealScreen from the tray before uninstalling so it restores your monitors. If a session ever crashed, run `"C:\Program Files\XrealScreen\xrs.exe" recover` to remove leftover virtual monitors and restore your layout.

## Known limitations
- Preview: first MSI, not yet tested on many PCs or with XREAL One / One Pro.
- Unsigned installer and test-signed driver (see *Security*).
- ARM64 and Windows 10 are not supported by this MSI.
- Head tracking in *App head tracking* has a little lag; *Glasses anchor* is the most stable type.
- The installer is large (~82 MB) because .NET and the Windows App SDK are included.
